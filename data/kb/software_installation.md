# Installing Approved Software

## Installing from the internal app catalog
1. Open the Company Portal / Self Service app on your machine.
2. Search for the application by name.
3. Click "Install" — most installs complete within 5 minutes and don't
   require a restart.
4. If installation fails with an error code, note the code and retry
   once; transient network errors during download are common.

## Requesting software not in the catalog
Software not listed in the catalog requires a license and security
review before it can be approved. Submit a request through the IT
request form with a business justification; approval typically takes
2-3 business days and cannot be expedited by this assistant.

## "Administrator permission required" errors
Standard user accounts cannot install software outside the approved
catalog. If a catalog install still asks for admin rights, restart your
computer and try again — a background policy sync from a fresh reboot
usually resolves this.

## Uninstalling software
Use "Apps & Features" (Windows) or drag the app to Trash (Mac) for
locally installed software. Catalog-managed apps should be removed via
the Company Portal to avoid leftover configuration.
